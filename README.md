# Ковш Центр / Naprawa Łyżek / Bucket Center

Многостраничный сайт по ремонту и восстановлению ковшей экскаваторов и фронтальных погрузчиков (Краков, Польша). Три языка: русский, польский, английский.

**Сайт:** https://naprawa-lyzek.vercel.app

## Страницы

| Страница | Файл |
|---|---|
| Главная | `index.html` |
| Ковши экскаваторов | `excavators.html` |
| Ковши погрузчиков | `loaders.html` |
| Наши работы | `works.html` |
| Контакты | `contacts.html` |

Каждая страница есть в трёх папках: `ru/`, `pl/`, `en/`. Корневой `index.html` выбирает язык по языку браузера.

## Что внутри

- Статический сайт, без сборки на стороне сервера. Страницы генерирует `build.py` из текстов в `content.py` (три языка).
- Анимации при скролле: GSAP + ScrollTrigger, плавный скролл Lenis (лежат в `assets/vendor/`).
- Фото и кейсы: `assets/img/`, `assets/vid/`.

## Запуск локально

```bash
python3 build.py          # пересобрать ru/pl/en
python3 -m http.server 8793
```

Открыть: http://localhost:8793/ru/index.html

## Редактирование текстов

Все тексты на трёх языках лежат в `content.py`. После правки запустить `python3 build.py`.
